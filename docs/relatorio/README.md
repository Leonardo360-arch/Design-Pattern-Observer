# Relatórios da equipe

Esta pasta é destinada aos relatórios de testes, problemas encontrados, sugestões de melhoria e observações durante a preparação da apresentação do padrão Observer.

## Como contribuir

1. Crie um arquivo Markdown nesta pasta, por exemplo: `relatorio-2026-11-17.md`.
2. Descreva o cenário testado, o comportamento esperado e o resultado observado.
3. Se houver problema, registre como reproduzi-lo e, se possível, a mensagem de erro.
4. Envie as alterações ao repositório por commit ou pull request, sem substituir o relatório de outro integrante.

## Modelo sugerido

```markdown
# Relatório — [nome do integrante] — [data]

## O que foi testado

## Resultado esperado

## Resultado obtido

## Problemas encontrados

## Passos para reproduzir

## Sugestões de melhoria

## Situação
Pendente / Resolvido / Não se aplica
```

Use dados fictícios de alunos nos testes.
